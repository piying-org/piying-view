本文介绍对象组（`v.object()` / `v.looseObject()` / `v.strictObject()`）在聚合值时的行为：模型里多出来的键怎么处理、键怎么动态新增、聚合不出值时输出什么。

## groupMode — 多余键的处理

模型里存在、schema 里没有的键，由 `groupMode` 决定怎么处理。`groupMode` 在解析 schema 时自动推导：

| schema                                       | 自动推导    | 多余键的处理                       |
| -------------------------------------------- | ----------- | ---------------------------------- |
| `v.object()`                                 | `default`   | 输出时丢弃，只留 schema 定义的键   |
| `v.looseObject()`                            | `loose`     | 保留并输出                         |
| `v.strictObject()`                           | `strict`    | 验证失败                           |
| `v.record()` / `v.objectWithRest()` 的 rest 部分 | `reset` | 不做固定键约束，键可动态新增       |

## 动态新增键

`v.objectWithRest()` 固定一部分键，其余键值按 rest 的类型动态添加；`v.record()` 的键值全部可动态添加。两者都推导为 `reset`：

<SchemaPreview definition="src/angular/components/definition/object-with-rest.definition.ts">
  <SchemaDemoComponent slot="preview" client:only="angular" name="objectWithRest" />
</SchemaPreview>

新增键时，键名要先过一次 `groupKeySchema`，不通过的键不会被创建：

<SchemaPreview definition="src/angular/components/definition/record-group-key-value.definition.ts">
  <SchemaDemoComponent slot="preview" client:only="angular" name="record-group-key-value" />
</SchemaPreview>

```typescript
v.pipe(
  v.record(v.string(), v.string()),
  formConfig({
    groupKeySchema: v.picklist(['name', 'email', 'phone']),
    groupValueSchema: v.pipe(v.string(), v.minLength(1)),
  }),
);
```

> 键值对的完整用法见 [Record Schema 动态对象组](zh/scenarios/record-dynamic-group/)。

## emptyValue — 聚合不出值时

组里的子字段一个值都没有时，最终值取 `emptyValue`：

<SchemaPreview definition="src/angular/components/definition/object-group-empty-value.definition.ts">
  <SchemaDemoComponent slot="preview" client:only="angular" name="object-group-empty-value" />
</SchemaPreview>

`profile` 的两个子字段都是 `v.optional()` 且没有值，输出即为 `emptyValue`；填了任意一个子字段，输出就是正常的键值对象。
