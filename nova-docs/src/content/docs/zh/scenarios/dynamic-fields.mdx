## hideWhen — 条件隐藏

### 基本用法：显示/隐藏额外字段

`hideWhen` 根据其他字段的值决定是否隐藏当前字段：

<SchemaPreview definition="src/angular/definition/dynamic-hide-when.definition.ts">
  <SchemaDemoComponent slot="preview" client:only="angular" name="dynamic-hide-when" />
</SchemaPreview>

当 `showExtra` 的值为 `false` 时，`extraField` 将被隐藏。

### hideWhen + disabled 联动

`hideWhen` 可同时控制 `hidden` 和 `disabled`：

<SchemaPreview definition="src/angular/definition/dynamic-hide-disabled.definition.ts">
  <SchemaDemoComponent slot="preview" client:only="angular" name="dynamic-hide-disabled" />
</SchemaPreview>

此时当 `enable` 为 `false` 时，`name` 字段**同时被隐藏和禁用**。

## disableWhen — 条件禁用

### 基本用法：基于其他字段禁用编辑

`disableWhen` 根据其他字段的值决定是否禁用当前字段：

<SchemaPreview definition="src/angular/definition/dynamic-disable-when.definition.ts">
  <SchemaDemoComponent slot="preview" client:only="angular" name="dynamic-disable-when" />
</SchemaPreview>

### disableWhen vs hideWhen.disabled

| 特性     | `disableWhen`      | `hideWhen({ disabled: true })` |
| -------- | ------------------ | ------------------------------ |
| 功能     | 仅控制 disabled    | 同时控制 hidden + disabled     |
| 适用场景 | 字段可见但不可编辑 | 字段不可见且不可编辑           |

详见 [API: disableWhen](zh/api/hide-disable/#disablewhen---类型签名)。
