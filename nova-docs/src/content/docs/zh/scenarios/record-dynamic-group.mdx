## Record 基本用法

`v.record(KeySchema, ValueSchema)` 定义一个键为字符串、值为指定类型的对象。Piying-View 将 `record` 映射为特殊的 Group，键由用户动态添加：

<SchemaPreview definition="src/angular/definition/record-basic.definition.ts">
  <SchemaDemoComponent slot="preview" client:only="angular" name="record-basic" />
</SchemaPreview>

在 `fieldGlobalConfig.types` 中确保 record 有对应的容器组件：

```typescript
options = {
  fieldGlobalConfig: {
    types: {
      record: { type: PiyingViewGroup }, // 使用 Group 容器处理动态键
    },
  },
};
```

## GroupKeySchema / GroupValueSchema

`FieldFormConfig` 提供 `groupKeySchema` 和 `groupValueSchema`，用于约束 Record 的键和值类型：

<SchemaPreview definition="src/angular/definition/record-group-key-value.definition.ts">
  <SchemaDemoComponent slot="preview" client:only="angular" name="record-group-key-value" />
</SchemaPreview>

> **注意**：`groupKeySchema` 和 `groupValueSchema` 用于约束动态添加的键值对，而非替换原有的 record schema。

## Record 验证行为

Record 字段的验证遵循标准 Group 规则：

<SchemaPreview definition="src/angular/definition/record-validation.definition.ts">
  <SchemaDemoComponent slot="preview" client:only="angular" name="record-validation" />
</SchemaPreview>

当 Record 中某个值不满足验证条件时，该键对应的子字段标记为错误，但不影响其他键的值。
