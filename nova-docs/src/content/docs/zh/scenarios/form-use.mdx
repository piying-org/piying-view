本文介绍表单的常用能力：值监听、布局移动、分区禁用、字段分组、验证、级联、懒加载等。

Valibot 类型如何映射为`表单控件` / `表单组` / `表单数组`，以及默认值与嵌套定义，统一见 [类型映射 — 定义即表单](zh/scenarios/type-mapping/)，本文不再重复。

## 值变更监听

`valueChange` 的 `list` 属性接受一个路径或者 `undefined`，通过路径查询到对应控件并监听输入值变更：

  <SchemaDemoComponent slot="preview" client:only="angular" name="form-use-value-change" />

> 更多联动场景（hideWhen / disableWhen / 级联 / 修改其他字段）见 [动态字段控制](zh/scenarios/dynamic-fields/)。

## 布局移动

表单中往往是数据结构与视图布局不一致，此时可在保证数据结构正常的前提下移动组件。被移动的位置一定要先被解析，权重越大组件越靠后：

<SchemaPreview definition="src/angular/components/definition/form-use-layout.definition.ts">
  <SchemaDemoComponent slot="preview" client:only="angular" name="form-use-layout" />
</SchemaPreview>

> 详细示例见 [asControl / asVirtualGroup](zh/scenarios/as-control-group/)。
