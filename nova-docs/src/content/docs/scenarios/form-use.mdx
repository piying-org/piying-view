## 类型映射

大部分 `Valibot` 类型会被解析为`表单控件`，以下为一些常用的类型。更多类型请到 [Valibot API](https://valibot.dev/api/) 中查看，自定义类型请使用 `custom`。

- `string`

```ts
v.string();
```

- `number`

```ts
v.number();
```

- `boolean`

```ts
v.boolean();
```

- `picklist`

```ts
v.picklist(['v1', 'v2', 'v3']);
```

> 上述控件类型映射的完整定义与可交互演示，见 [类型映射 — 定义即表单](type-mapping/)。

---

以下类型会被解析为`表单组`，均可在内部通过 `__helper` 引用 `formHelper` 组件来展示校验错误、提交/重置按钮：

### object / strictObject — 自动过滤未定义的键值

<SchemaPreview definition="src/components/definition/form-use-object.definition.ts">
  <SchemaDemoComponent slot="preview" client:only="angular" name="form-use-object" />
</SchemaPreview>

```ts
{
  model: { k1: 'v1', k2: 2 },
  schema: v.object({
    k1: v.string(),
    k2: v.number(),
    __helper: v.pipe(NFCSchema, setComponent('formHelper')),
  }),
}
```

### looseObject — 保留未定义的键值

<SchemaPreview definition="src/components/definition/form-use-loose-object.definition.ts">
  <SchemaDemoComponent slot="preview" client:only="angular" name="form-use-loose-object" />
</SchemaPreview>

```ts
{
  model: { k1: 'v1', k2: 2 },
  schema: v.looseObject({
    k1: v.string(),
    k2: v.number(),
    __helper: v.pipe(NFCSchema, setComponent('formHelper')),
  }),
}
```

### objectWithRest — 部分固定键值，部分可添加

<SchemaPreview definition="src/components/definition/form-use-object-with-rest.definition.ts">
  <SchemaDemoComponent slot="preview" client:only="angular" name="form-use-object-with-rest" />
</SchemaPreview>

```ts
{
  model: { k1: 'v1', k2: 2 },
  schema: v.intersect([
    v.objectWithRest(
      {
        k1: v.string(),
        k2: v.number(),
      },
      v.string(),
    ),
    v.optional(
      v.object({
        __helper: v.pipe(NFCSchema, setComponent('formHelper')),
      }),
    ),
  ]),
}
```

### record — 无固定键值，全部为可添加键值

> 目前仅支持 key 为 string 类型。

<SchemaPreview definition="src/components/definition/form-use-record.definition.ts">
  <SchemaDemoComponent slot="preview" client:only="angular" name="form-use-record" />
</SchemaPreview>

```ts

  model: { o1: { k1: 'v1' } },
  schema: v.intersect([
    v.object({
      o1: v.record(v.string(), v.string()),
    }),
    v.optional(
      v.object({
        __helper: v.pipe(NFCSchema, setComponent('formHelper')),
      }),
    ),
  ]),
}
```

## 默认值

`v.optional()` 的第二个参数即为默认值，渲染后直接填入表单：

```ts
v.object({
  k1: v.optional(v.string(), 'default value'),
});
```

## 值变更监听

`valueChange` 的 `list` 属性接受一个路径或者 `undefined`，通过路径查询到对应控件并监听输入值变更：

```ts
import { valueChange } from '@piying/view-angular-core';

v.object({
  k1: v.pipe(
    v.string(),
    valueChange((fn) => {
      fn({ list: [undefined] }).subscribe(({ list }) => {
        console.log(list[0]);
      });
    }),
  ),
});
```

> 更多联动场景（hideWhen / disableWhen / 级联 / 修改其他字段）见 [动态字段控制](dynamic-fields/)。

## 布局移动

表单中往往是数据结构与视图布局不一致，此时可在保证数据结构正常的前提下移动组件。被移动的位置一定要先被解析，权重越大组件越靠后：

```ts
import { asVirtualGroup, PiyingViewGroup } from '@piying/view-angular';
import { layout, setAlias, setComponent } from '@piying/view-angular-core';

const schema = v.pipe(
  v.intersect([
    v.pipe(v.object({}), setComponent(PiyingViewGroup), setAlias('ly1')),
    v.pipe(v.object({}), setComponent(PiyingViewGroup), setAlias('ly2')),
    v.object({
      input1: v.pipe(v.string(), layout({ keyPath: ['@ly1'] })),
      input2: v.pipe(v.string(), layout({ keyPath: ['@ly2'], priority: 3 })),
      input3: v.pipe(v.string(), layout({ keyPath: ['@ly2'], priority: 2 })),
      input4: v.pipe(v.string(), layout({ keyPath: ['@ly2'], priority: 1 })),
      __helper: v.pipe(NFCSchema, setComponent('formHelper')),
    }),
  ]),
  asVirtualGroup(),
);
```

> 详细示例见 [asControl / asVirtualGroup](as-control-group/)。

## 分区禁用

当表单部分字段在某些场景可以/不可以被填写时，使用 `disableWhen`：

```ts
import { disableWhen } from '@piying/view-angular-core';
import { map } from 'rxjs';

v.object({
  enable: v.boolean(),
  value: v.intersect([
    v.pipe(
      v.object({
        input1: v.string(),
        input2: v.string(),
      }),
      disableWhen({
        listen: (fn) => {
          return fn({ list: [['#', 'enable']] }).pipe(
            map(({ list }) => list[0]),
          );
        },
      }),
    ),
    v.pipe(
      v.object({
        input3: v.string(),
        input4: v.string(),
      }),
      disableWhen({
        listen: (fn) => {
          return fn({ list: [['#', 'enable']] }).pipe(
            map(({ list }) => !list[0]),
          );
        },
      }),
    ),
  ]),
});
```

## 数组

任何情况下，都可以将指定类型定义外加入 `v.array()`，表明为一个数组：

```ts
import { actions } from '@piying/view-angular';
import { setComponent } from '@piying/view-angular-core';

v.object({
  list: v.pipe(v.array(v.string()), setComponent('array-rw'), actions.inputs.set({ minLength: 2 })),
});
```

> 数组的增删改、deletionMode、groupMode 等高级用法见 [数组高级用法](array-advanced/)。

## 嵌套定义

使用 `object` 可以进行多级数据结构定义，自动嵌套渲染为子表单组：

```ts
import { actions } from '@piying/view-angular';
import { setComponent, valueChange } from '@piying/view-angular-core';

v.pipe(
  v.object({
    k1: v.pipe(v.string(), v.title('一级k1'), actions.wrappers.set(['label'])),
    o1: v.pipe(
      v.object({
        k2: v.pipe(v.optional(v.string()), v.title('二级k2'), actions.wrappers.set(['label'])),
        k3: v.pipe(v.optional(v.string()), v.title('二级k3'), actions.wrappers.set(['label'])),
      }),
      setComponent('fieldset'),
      v.title('一级o1'),
    ),
  }),
  setComponent('fieldset'),
  valueChange((fn) => {
    fn().subscribe(({ list }) => {
      console.log(list[0]);
    });
  }),
);
```

## 字段分组

`v.intersect()` + `asVirtualGroup` 可以进行多级虚拟组，配合 `tabs` 组件实现标签页分组：

```ts
import { asVirtualGroup } from '@piying/view-angular';

v.pipe(
  v.intersect([
    v.pipe(
      v.object({
        k1: v.optional(v.string()),
        k2: v.optional(v.string()),
      }),
      setComponent('fieldset'),
      v.title('tab1-fieldset'),
    ),
    v.pipe(
      v.object({
        k3: v.optional(v.string()),
        k4: v.optional(v.string()),
      }),
      v.title('tab2'),
    ),
  ]),
  setComponent('tabs'),
  asVirtualGroup(),
  valueChange((fn) => {
    fn().subscribe(({ list }) => {
      console.log('tabs', list[0]);
    });
  }),
);
```

## 值变更时修改表单其他值

使用 `valueChange` 监听控件并更新其他控件的值：

```ts
import { valueChange } from '@piying/view-angular-core';

v.object({
  list: v.pipe(
    v.picklist(['data1', 'data2']),
    valueChange((fn) => {
      fn().subscribe(({ list: [value], field }) => {
        const o1FG = field.get(['#', 'o1']).form.control;
        const o2FG = field.get(['#', 'o2']).form.control;
        if (value === 'data1') {
          o1FG.updateValue({ k1: 'data1-input-k1', k2: 'data1-input-k2' });
          o2FG.updateValue({});
        } else {
          o2FG.updateValue({ k3: 'data2-input-k3', k4: 'data2-input-k4' });
          o1FG.updateValue({});
        }
      });
    }),
  ),
  o1: v.object({ k1: v.optional(v.string()), k2: v.optional(v.string()) }),
  o2: v.object({ k3: v.optional(v.string()), k4: v.optional(v.string()) }),
});
```

## 验证

验证和控件组件完全解耦，需要自行实现，只提供相关控件状态。可以使用 `wrapper` 套一层实现，也可以使用 group 只在专门的组中进行验证：

```ts
import { setComponent } from '@piying/view-angular-core';

v.pipe(
  v.object({
    k1: v.pipe(
      v.string(),
      v.check((value) => value === 'k2-value', 'should input k2-value'),
      actions.wrappers.set(['validator']),
    ),
  }),
);
```

```ts
import { setComponent } from '@piying/view-angular-core';

v.pipe(
  v.object({
    k1: v.string(),
    k2: v.pipe(
      v.string(),
      v.check((value) => value === 'k2-value'),
    ),
  }),
  setComponent('validGroup'),
);
```

> 同步/异步验证器、formConfig.validators 等详细用法见 [自定义验证](custom-validation/)。

## 级联

通过 `valueChange` 监听指定控件并更新控件值。第一次监听的值默认为 `undefined`（假如没有设置默认值），所以需要跳过：

```ts
import { valueChange } from '@piying/view-angular-core';
import { skip } from 'rxjs';

v.object({
  k1: v.boolean(),
  k2: v.pipe(
    v.boolean(),
    valueChange((fn) => {
      fn({ list: [['#', 'k1']] })
        .pipe(skip(1))
        .subscribe(({ list: [value], field }) => {
          field.form.control?.updateValue(!value);
        });
    }),
  ),
  k3: v.pipe(
    v.boolean(),
    valueChange((fn) => {
      fn({ list: [['#', 'k2']] })
        .pipe(skip(1))
        .subscribe(({ list: [value], field }) => {
          field.form.control?.updateValue(!value);
        });
    }),
  ),
  k4: v.pipe(
    v.boolean(),
    valueChange((fn) => {
      fn({ list: [['#', 'k3']] })
        .pipe(skip(1))
        .subscribe(({ list: [value], field }) => {
          field.form.control?.updateValue(!value);
        });
    }),
  ),
});
```

## 过滤组

自定义创建表单组控制内部表单的显示（大量字段时可使用 `filterGroup` 过滤组件）：

```ts
import { setComponent } from '@piying/view-angular-core';

const schema = v.pipe(
  v.object(
    new Array(100)
      .fill(undefined)
      .map((item, i) => v.pipe(v.string(), v.title(`SearchTitle${i}`)))
      .reduce((obj, item, i) => {
        obj[`k${i}`] = item;
        return obj;
      }, Object.create({})),
  ),
  setComponent('filterGroup'),
);
```

> 可交互示例见 [数组高级用法 — 过滤组](array-advanced/#过滤组)。

## 滚动组

使用 `defer` 动态创建控件，配合 `scrollGroup` 组件实现大量字段的滚动懒加载：

```ts
import { actions } from '@piying/view-angular';
import { setComponent } from '@piying/view-angular-core';

const schema = v.pipe(
  v.object(
    new Array(100)
      .fill(undefined)
      .map((item, i) => v.pipe(v.string(), v.title(`title${i}`)))
      .reduce((obj, item, i) => {
        obj[`k${i}`] = item;
        return obj;
      }, Object.create({})),
  ),
  setComponent('scrollGroup'),
  actions.inputs.set({ scrollHeight: 500, placeholerHeight: 20 }),
);
```

> 可交互示例见 [数组高级用法 — 滚动组](array-advanced/#滚动组)。
