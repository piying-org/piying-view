## Nesting (Nested Objects)

Define nested object structures with `v.object()`; Piying-View maps the `object` type to a Group component and renders children recursively:

<SchemaPreview definition="src/angular/definition/complex-nesting.definition.ts">
  <SchemaDemoComponent slot="preview" client:only="angular" name="complex-nesting" />
</SchemaPreview>

Make sure object has a container component in `fieldGlobalConfig.types`:

```typescript
options = {
  fieldGlobalConfig: {
    types: {
      object: { type: PiyingViewGroup }, // the Group container handles nesting
    },
  },
};
```

## Array (List Fields)

Define list fields with `v.array()`; Piying-View maps `array` to `FieldArray` and renders it with the array container component:

```typescript
options = {
  fieldGlobalConfig: {
    types: {
      array: { type: PiyingViewGroup }, // the Array container handles lists
    },
  },
};
```

## Intersect (Intersection Types)

Merge several objects with `v.intersect()`; Piying-View turns `intersect` into a `FieldLogicGroup` and flattens all children to the same level:

<SchemaPreview definition="src/angular/definition/complex-intersect.definition.ts">
  <SchemaDemoComponent slot="preview" client:only="angular" name="complex-intersect" />
</SchemaPreview>

`layout` adjusts the order and position of fields inside an `intersect`:

```typescript
import { layout } from '@piying/view-angular-core';

const schema = v.intersect([v.pipe(v.object({ name: v.string() }), layout({ priority: 1 })), v.pipe(v.object({ age: v.number() }), layout({ priority: 2 }))]);
```

## Schema Type → FieldControl Mapping

| Valibot Schema                              | FieldControl class | View appearance            |
| ------------------------------------------- | ----------------- | -------------------------- |
| `v.string()` / `v.number()` / `v.boolean()` | `FieldControl`     | A single input control       |
| `v.object()`                                | `FieldGroup`       | Object container (renders the child list) |
| `v.array()`                                 | `FieldArray`       | Array container (items can be added/removed) |
| `v.tuple()`                                 | `FieldArray`       | Fixed-length array           |
| `v.record()`                                | `FieldGroup`       | Dynamic key/value container  |
| `v.intersect()`                             | `FieldLogicGroup`  | Logical grouping (merged fields) |
| `v.union()`                                 | `FieldLogicGroup`  | Logical grouping (branch switching) |
