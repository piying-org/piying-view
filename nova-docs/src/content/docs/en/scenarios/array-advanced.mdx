## Basic Array Operations

Piying-View's FieldArray provides these methods:

### set — set the value at an index

Call `field.action.set(value, index)` directly:

```typescript
field.action.set('newValue', 0); // set the value at index 0 to 'newValue'
```

Inserting past leading elements is supported:

```typescript
field.action.set('value', 5); // set a value at index 5
```

### remove — remove the element at an index

Call `field.action.remove(index)` directly:

```typescript
field.action.remove(0); // remove the element at index 0
```

### updateValue — replace the whole array

Call `field.form.control.updateValue(value)` directly:

```typescript
field.form.control.updateValue(['a', 'b', 'c']); // replace the whole array content
```

### clear — empty the array

Call `field.form.control.clear()` directly:

```typescript
field.form.control.clear(); // remove every element
```

## groupMode — Group Validation Mode

Controls the validation behaviour of Group / Array. `groupMode` is inferred automatically while parsing the schema and never needs to be set.

| Schema type                        | Inferred `groupMode` | Description                   |
| -------------------------------- | ---------------------- | ---------------------------- |
| `v.object()`                     | `'default'`            | Standard object: filters out undefined extra keys on output |
| `v.looseObject()`                | `'loose'`              | Loose object: keeps undefined extra keys |
| `v.strictObject()`               | `'strict'`             | Strict object: validation fails when extra keys exist |
| `v.tuple()`                      | `'default'`            | Fixed-length tuple: items beyond the length are truncated |
| `v.looseTuple()`                 | `'loose'`              | Loose tuple: items beyond the length are kept |
| `v.strictTuple()`                | `'strict'`             | Strict tuple: validation fails when the length is exceeded |
| `v.array()` / the rest part of `v.tupleWithRest()` | `'reset'` | Array / variable tail: no fixed-key or length constraint |
| `v.intersect()` + `asVirtualGroup()` | Configurable     | Equivalent to `v.object()`     |

## Array Properties

FieldArray exposes convenient array-related properties:

| Property                 | Type             | Description                       |
| ------------------------ | ---------------- | -------------------------------- |
| `field.length`           | `number`         | Number of current child controls (fixed + dynamic) |
| `field.controls`         | `FieldControl[]` | Current child controls            |
| `field.fixedControls$()` | `FieldControl[]` | Fixed child controls (excluding rest children) |
| `field.resetControls$()` | `FieldControl[]` | All resettable child controls      |

## Examples

> The examples below are excerpted from the unit tests (`createBuilder` is an internal test utility, not a public API).

```typescript
// Array set + remove
const obj = v.object({
  key1: v.pipe(v.array(v.string()), setComponent('mock-array')),
});

const resolved = createBuilder(obj);
const field = resolved.get(['key1'])!;

field.action.set('11', 1); // set '11' at index 1
field.action.remove(0); // remove index 0
```
