This page covers the common form capabilities: value listening, layout moves, section disabling, field grouping, validation, cascading and lazy loading.

How Valibot types resolve into form controls / form groups / form arrays, plus default values and nested definitions, lives exclusively in [Type Mapping — Definition Is the Form](en/scenarios/type-mapping/) and is not repeated here.
