This page demonstrates the core "definition is the form" capability: a Valibot type definition renders automatically into the matching form control. Every definition below renders an interactive form.

Rendering relies on the global field configuration `FieldGlobalConfig` (implicit types such as `string`/`number`/`boolean`/`picklist` map to their controls), passed through `options`:

```typescript
import { PresetDefine } from '@piying-lib/angular-daisyui/preset';

export const FieldGlobalConfig = PresetDefine;

options = { fieldGlobalConfig: FieldGlobalConfig };
```

## Form Group Types

An object defined with `v.object()` renders as a form group containing every child field automatically. Inside any group you can reference the `formHelper` component through `__helper` to render validation errors and submit / reset buttons.
