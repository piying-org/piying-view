### Basic Usage: Showing/Hiding an Extra Field

## disableWhen — Conditional Disabling

### Basic Usage: Disabling Editing Based on Other Fields

`disableWhen` decides whether to disable the current field based on the value of another field:

<SchemaPreview definition="src/angular/definition/dynamic-disable-when.definition.ts">
  <SchemaDemoComponent slot="preview" client:only="angular" name="dynamic-disable-when" />
</SchemaPreview>

### disableWhen vs hideWhen.disabled

| Feature     | `disableWhen`       | `hideWhen({ disabled: true })` |
| -------- | ------------------ | ------------------------------ |
| Capability  | Controls disabled only | Controls hidden + disabled    |
| When to use | Field visible but not editable | Field invisible and not editable |

See [API: disableWhen](en/api/hide-disable/).
