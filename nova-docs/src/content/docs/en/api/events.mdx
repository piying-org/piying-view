Bind native DOM events with `actions.events.patchAsync`:

> ⚠️ The value of each key is a curried function that **receives `field` and returns the event handler**: `(field) => (event) => {...}` — only the inner function is actually bound to the DOM event. When you don't need `field`, just ignore the first argument (as in `click: (field) => (event) => {...}` below).

> Events are bound to the **host element** of the field component: V1 components support this out of the box; V2 components (`static __version = 2`, selectorless) must set events manually.
