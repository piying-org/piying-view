Playground 使用说明

代码需要返回 {schema, model?, context?, builderType?} 对象。

代码中可直接使用的变量：
@for (item of injectedVars; track item) { {{ item }} }
可用的组件类型（与文档站点同一份 fieldGlobalConfig）：
@for (item of componentTypes; track item) { {{ item }} }

builderType: 'translate' 会切换到 translate builder，此时需要在 context 中提供 lang（BehaviorSubject）与 i18n。

「复制分享链接」会把当前代码写入 URL 的 input 参数；也可以自行构造 ?input=<JSON 字符串>，对象字面量或裸 schema 表达式会自动包装成可执行代码。

编辑器内置类型声明，编写时会有补全与错误提示。
