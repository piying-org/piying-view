JSON Schema Playground 使用说明

左侧输入 JSON Schema（支持 Draft-04、Draft-07、Draft 2020-12），右侧实时渲染表单。

输入内容可以是 JSON Schema 本身，也可以是 {schema, model} 包装对象，后者可以顺便指定初始值。

转换本质是 jsonSchemaToValibot() ，详见 JSON Schema 支持。

「复制分享链接」会把当前 JSON 写入 URL 的 input 参数，也可自行构造 ?input=<JSON 字符串>。
